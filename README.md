# Student Management System

## Project Description

The Student Management System is a menu-driven application developed using C programming. It uses a Singly Linked List to manage student records dynamically and File Handling to store and retrieve student information.

## Features

* Add student records
* Delete student records
* Display student details
* Modify student information
* Save student records to a file
* Sort records by name or percentage
* Load previously saved records

## Technologies Used

* Programming Language: C
* Data Structure: Singly Linked List
* Concept: File Handling
* Operating System: Linux (Ubuntu)
* Build Tool: GNU Make

## Project Files

| File Name     | Description                     |
| ------------- | ------------------------------- |
| `main.c`      | Main menu and program execution |
| `stud_add.c`  | Add student records             |
| `stud_del.c`  | Delete student records          |
| `stud_show.c` | Display student records         |
| `stud_mod.c`  | Modify student information      |
| `stud_save.c` | Save and load student records   |
| `stud_sort.c` | Sort student records            |
| `makefile`    | Compile the project             |

## Compilation and Execution

### Compile the project

```bash
make
```

### Run the application

```bash
./student
```

### Clean generated files

```bash
make clean
```

## Circuit Details

Not applicable. This is a software-based project developed using C programming.
